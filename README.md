# FMCG Sales Copilot

> **All data is synthetic and for demonstration only; it does not represent real company sales, prices or volumes.**

An AI copilot for beverage sales reps and commercial managers: it answers sales questions,
forecasts demand, recommends what each outlet should order, and answers promotions-policy
questions, grounded in data.

*Work in progress. The full README (architecture, results, how to run) is written in the last phase.*
